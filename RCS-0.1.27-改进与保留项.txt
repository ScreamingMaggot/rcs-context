RCS 0.1.27 改进与保留项
================================================================================
插件版本：CONTEXTinjector v1.10.31（压缩比口径修正）；WebUI 面板同步
上一版：0.1.26（当前轮保护：折叠不再吃掉仍在飞的那一轮）
回退点：rcs-0.1.27 → rcs-0.1.26 → … → rcs-0.1.8

本版主题：**折叠"压缩比"口径修正 —— 从"累计除本折"改回"本折除本折"，并按历史重算**


--------------------------------------------------------------------------------
一、症状（用户报告："每轮压缩比也很失真"）
--------------------------------------------------------------------------------
面板「最近一次折叠」显示 `遮蔽 → 转录 (百分比)`，其中百分比取 `shrink`。真机读数：

    session-de4959d2  显示 659%     session-5fe3512e 某笔  显示 917%
    session-ffab17e9  显示 382400%


--------------------------------------------------------------------------------
二、根因：分子分母来自**不同折**
--------------------------------------------------------------------------------
    shrink = transcriptBytes / shadowedBytes
             └─ 累计转录（foldText 全长）   └─ **本折**遮蔽字节

首次折叠时二者同源（累计=本折），所以看着正常；增量折叠上分子含历史全部转录，
分母只算本折 ⇒ 结构性 >1，且折得越多越离谱。**这不是"折叠没收益"，是混合口径**。

同源的还有两处 console 输出（fold-attempt / fold-committed 各一行），都拿这两个数相除。


--------------------------------------------------------------------------------
三、修法
--------------------------------------------------------------------------------
1. 抽出纯函数 `foldShrinkOf({appendedBytes, incrementalRawBytes, transcriptBytes, shadowedBytes})`：
   本折口径 = 本次新增转录 ÷ 本次被转写的新原料；缺增量数据的旧记录（v1.10.25 之前）回退旧算式，
   保证字段恒为数值而非崩溃。三处引用（fold-attempt 日志 / fold-committed 日志 / last-fold 落盘）全部改走它。
2. 新增字段 `foldShrinkScope: 'this-fold(appended/incrementalRaw)'`，让记录自带口径说明，
   下次再有疑问不必反推。
3. `transcriptBytes`（累计转录长度）**原样保留**——它本身没错，只是不该当收益指标。
4. 面板同步：显示改为本折的 `incrementalRawBytes → appendedBytes B (本折占比%)`；
   旧记录缺该字段时自动回退显示原值，不会空白。

**为什么不能只改面板**：口径错了，任何消费方（导出、面板、账本）都会算错。修在源头，面板只是展示。


--------------------------------------------------------------------------------
四、按历史重算（用户要求）
--------------------------------------------------------------------------------
对 `~/.dsh/state-compiler` 下所有 last-fold 记录就地重算 `shrink`：

    重算 12 个文件，跳过 11 个（v1.10.25 之前的记录无增量字段，按设计不动）

    session-de4959d2   6.5863 (659%)     → 0.6230 (1.61×)
    session-5fe3512e   9.1685 (917%)     → 0.3464 (2.89×)
    session-ffab17e9   3824.05 (382400%) → 0.9000 (1.11×)
    session-8e692134   0.1004            → 0.1434 (6.97×)
    session-bbfd2f6a   0.1998            → 0.0973 (10.28×)
    …（其余略）

安全：每个文件**先备份**（`.bak-<stamp>-before-shrinkfix`），旧值另存 `shrinkLegacy` 不做无痕覆盖。

真机会话 5fe3512e 五笔折叠的正确本折读数（供对外引用）：

    第 1 折 465,068 →  57,099 B   7.84×      第 4 折 197,939 →  37,186 B   5.32×
    第 2 折 648,362 → 114,123 B   5.68×      第 5 折   4,946 →   3,162 B   1.56×
    第 3 折 293,978 →  80,954 B   3.63×      合计  1,610,293 → 292,524 B   5.50×
