# 记忆面板 UI 差距账

本文件记录「记忆」面板（图谱 / 列表 / 设置）与前沿知识图谱、AI 记忆产品的差距，以及每一项的证据、状态与验收口径。评分来自 2026-10-24 的三路无背景评审（盲评截图、只读代码审计、任务可用性红队），随后由 live 真机复核。勿把评审里的合成数据误判当成产品缺陷；误判列在文末。

## 当前结论

- 综合约 **4.3/10**，处于「有明确产品形态的 v1」，距世界一流（8–9）差 1–2 个代际。
- 强项：事实生命周期（7）、来源/作用域分层（6）、列表与设置（7）。
- 弱项：事实可读性（3）、证据钻取（4）、交互完整度（3）、规模（3）、无障碍（2）。
- 定位判断：目前是「来源查看器」，还不是「记忆分析工具」。

## 本轮验收（2026-10-24，live DSH 0.2.1-rc.3）

- 视口：1280×860，当前上下文 9 条事实 → 事实标签 5 条、标签重叠 0、默认视口裁切 0；选中事实后详情栏出现 4 条证据（kind / 内容 / 时间 / 来源会话 / seq），可展开原始 JSON。
- 展开全部 29 节点，滚轮至 1.76× → 9 条事实标签、重叠 0；未参与显示的由贪心避让或”前 6 条”规则隐藏，悬停/选中可单独调出。
- viewBox 改为跟随容器比例（900×330 而非固定 900×560），同一视口下有效缩放从 0.39 提到 0.667，标签实际字号约 1.7×。
- 列表卡片来源徽标「工作区共享 / 本会话私有」上线；详情栏字段为「事实类型 / 生命周期」。
- 键盘：焦点从工作区 → 方向键到事实 → Enter 打开详情（4 条证据）→ Esc 返回；roving tabindex 只有 1 个 0；焦点环 1 个。
- 聚焦模式：1280×860 图谱 275→430px，viewBox 900×620，概览条 `display:none`，退出后恢复。
- 布局缓存：215 节点合成图首帧 14.24ms，缓存重绘 30 次均值 1.03ms（p50 1.0、max 1.6）。
- 服务端钻取：live `range=all&factLimit=5` → 显示 5 / 共 27 条、truncated；聚焦 TESTSPACE → 7 条；聚焦会话 → 4 条；客户端请求实测带 `factLimit=500&focusScope=ws%3A…`，清除聚焦后回到 `factLimit=200` 且无 focusScope。
- 时间窗：live 全部 27 条、最近 1 天 16 条、7/30/90 天均 27 条；客户端选择最近 7 天时请求带 `sinceTs=1792252800000`（本地零点）。窄屏重回单行工具条：wrapBottom 502 < composerTop 524。
- 游标分页：live `range=all&factLimit=3&focusScope=ws%3A…/plugintestplace` → 首页 3 条事实、`hasMore=true`、`nextCursor=1792771461305:126`；第二页沿用游标 → 3 条事实、与首页无重叠、`cursor` 回显、`hasMore=true`；`factTotal=20` 不受游标影响。客户端列表页聚焦时显示”加载更早”按钮，合并去重后计数”已载入 N / 共 M 条事实（含更早 K 条）”；图谱页不追加旧页，提示”切到列表可加载更早的事实”。
- 图谱独立端点：`/api/memory/graph` 只返回 `{nodes, edges, stats}`，`/api/memory/status` 的 graph 字段设为 null；5s 轮询负载从 51KB 降至 18KB（减 64.9%）。
- 框选多节点：Ctrl/Shift 点击追加/取消选择，拖拽空白区域框选多个节点；多选时详情栏显示摘要（工作区/会话/洞察分类计数）。
- 路径传播高亮：选中节点后沿边 BFS 找出所有可达节点，整条来源链路（fact → session → workspace）一起高亮；边的 `on` 类要求两端都在 `pathSet` 内。
- 屏幕阅读器审计：所有交互元素补全 ARIA 属性与键盘支持（会话/记录 chip、组头、tab、select、缩放按钮、可折叠文本、错误消息）。
- 失败态内嵌：图谱/列表加载失败时在画布/列表区域内显示错误原因与重试按钮，而非只在顶部显示 err。
- DSH 版本兼容：已验证兼容 DSH 0.2.1-rc.3（2026-10-23 发布），全套测试通过。
- 阻塞 join 回归（v1.10.57）：`agent/pre-step` 改回 `await joinFoldInFlight()`，新消息必须等压缩完成（带 3s 超时闸）再放行，保证每轮都吃到压缩增益；非阻塞版本（v1.10.53）导致用户开压缩但吃不到增益。
- 数据库备份机制（v0.5.7）：`backupDatabase()` 在破坏性操作（workspace reset）前自动备份 SQLite，备份存放在 `memory/backups/`，时间戳精确到毫秒，默认保留最近 5 份（`DSH_MEMORY_BACKUP_KEEP` 可调）。
- 回归：`node tests/run-all.mjs` → 42/42 套、994/994 断言、16.0s。

## 已修复缺陷（真机复核）

| 缺陷 | 根因 | 验证 |
|---|---|---|
| 开页即滚轮缩放无响应 | wheel effect 只依赖 `tab`，首帧数据未到时 svg 未渲染，effect 提前返回后不再重跑 | CDP：`defaultPrevented=true`；缩放后光标锚点漂移 0.12/0.06 图坐标单位 |
| 拖拽平移偏慢 | 屏幕像素被直接当 viewBox 单位 | CDP：70px 拖拽 → 178.18 单位（理论 178.2） |
| 未知会话渲染空图 | 客户端没采纳服务端 `rangeEffective` | `sessionId` 不存在 + `range=current` → `all`、43 节点/66 边 |
| 计数单位含混 | 概览/侧栏/设置只写数字 | 全部显式到「记录 / 洞察」；工具条有「范围 / 类型 / 状态」标签 |
| 浅色与窄屏可读性 | 浅色边线/标签对比不足；标签偏小 | 浅色 1280×860 标签 `rgb(27,31,39)`；窄屏 816 标签 17px |

## 评审误判（不作为缺陷处理）

- 「TESTSPACE 165 < 全库 178」：合成 fixture 数字；真机为 174 / 72。
- 「范围只有 current/all」：只看折叠后的 select，实际四档。
- 「列表没有选中态」：真机可选且保留。
- 「私有边缺失」：样本本来没有私有 insight。
